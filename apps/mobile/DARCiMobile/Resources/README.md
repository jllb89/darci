# DARCi Mobile Resources

- `Assets.xcassets/`: compiled image sets, app icon, accent color, and production UI assets referenced by name in SwiftUI.
- `Fonts/Maison/`: Maison Neue TTF files registered in `project.yml` through `UIAppFonts`.
- `Icons/`: source or raw icon files before they are promoted into the asset catalog.
- `Images/`: raw photos and bitmap imagery.
- `Illustrations/`: onboarding and editorial artwork.
- `Data/`: bundled JSON or other static data.
- `Localization/`: strings files and localized resource variants.
